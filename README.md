# 5 Basic Python Projects

A collection of 5 simple Python scripts I built to practice my coding skills.

## Projects Included

1. **Password Generator** - Generates a secure, random password.
2. **Typing Speed Check** - Tests how fast you can type a sentence.
3. **Word Guessing Game** - A simple text-based word guessing game.
4. **QR Code Generator** - Converts text or links into a QR code.
5. **Advanced Password Generator** - A password tool with more customization.

## Requirements
The QR Code project requires the `qrcode` library. You can install it using:

pip install qrcode pillow
